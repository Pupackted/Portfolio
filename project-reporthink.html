ReporthinkTemplate Editor

Static templates, made editable.

Reporthink.ai offers ready-made report templates: sustainability reports, annual reports, company profiles. Users could pick one, but they couldn’t change a word of it. I built the editor that lets them edit the text and colours, swap the photos, rearrange the pages, save, and export an A4 PDF, all in the browser.

03The real editor

The real thing, annotated.

  1. 1

    Pages are Template Parts

    Every page, from the cover to the director’s message to the closing page, is a part from the template’s library. Add one, reorder them, or delete what you don’t need.

  2. 2

    Colour and type, per element

    A real-time colour picker restyles the selected element. Text gets fonts, bold, italic and alignment.

  3. 3

    Click or drop to replace

    Placeholder photos and logos are swapped by clicking them, or by dragging a new file straight onto the canvas.

  4. 4

    Download as PDF

    html2canvas renders each page and jsPDF assembles them into a print-ready A4 PDF.

  5. 5

    Save, come back later

    Your work is saved as your own document. The master template stays untouched, and your edits wait in your dashboard.

04How it’s built

Masters stay masters.

The whole data model protects one rule: a template is never edited. Using one creates a UserDocument, your own copy, so the originals stay untouched for every other user.

Back endPython & Django, on Django’s MVT architecture.
Front endTailwind CSS via django-tailwind, and vanilla JavaScript for the editor’s DOM work.
DatabaseSQLite in development, PostgreSQL-ready through the Django ORM.
PDF exporthtml2canvas + jsPDF, rendered in the browser to A4.
AdminDjango admin to manage templates and their parts.

06My role

What I built.

I joined Mediawave’s Reporthink.ai team as a front-end intern. Alongside the team’s template work, I designed and built the Template Editor end to end.

  1. 01

    End-to-end build

    Built the back-end logic in Django, and the editor’s interactive front end in JavaScript and Tailwind CSS.

  2. 02

    System design

    Designed the database schema (ERD) that keeps users, master templates, their parts and each user’s edits apart.

  3. 03

    UI/UX

    Designed the wireframes, high-fidelity mockups and the final responsive interface, in Reporthink.ai’s branding.

  4. 04

    Testing & QA

    Wrote unit tests for authentication and the database models, and ran user acceptance testing to refine the flow.
