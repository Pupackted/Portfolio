MUOOD

macOS · Old devices

Making Use Of Old Device: a phone you stopped using becomes a live companion display for your Mac. Now playing with time-synced lyrics, a deck of buttons, Control Center for volume, brightness, mic and keep-awake, vitals like CPU, memory and battery, your repos and deploys, weather and a clock. Apple’s StandBy, but it does far more — and because it’s a web app, almost any old screen can run it over USB or Wi-Fi.
